# Wedding SVG artwork

Downloaded on 2026-11-25. Original vector geometry is preserved. The invitation applies its ink colours with CSS masks.

- `rose-sprig.svg` is **Vintage flowers rose 3** by maxim2, downloaded from [Openclipart](https://openclipart.org/detail/191745/vintage-flowers-rose-3). Released under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).
- `diamond-ring.svg` is **diamond-ring** from ByteDance IconPark. [Official source](https://github.com/bytedance/IconPark/blob/master/source/Clothes/diamond-ring.svg). Apache 2.0 license is included in `ICONPARK-LICENSE`.
- `joined-hearts.svg` is **hearts-line** from Remix Icon. [Official source](https://github.com/Remix-Design/RemixIcon/blob/master/icons/Health%20%26%20Medical/hearts-line.svg). Remix Icon License v1.0 is included in `REMIX-LICENSE`.

The champagne motif uses the existing Phosphor asset and MIT license in `public/icons`.
