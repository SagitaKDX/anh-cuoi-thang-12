# Invitation typography

Self-hosted WOFF2 files from Google Fonts, retrieved on 2026-11-25.

- [Cormorant Garamond](https://fonts.google.com/specimen/Cormorant+Garamond): variable weights 400–600, normal and italic.
- [Be Vietnam Pro](https://fonts.google.com/specimen/Be+Vietnam+Pro): weights 400 and 500, normal.

Latin, Latin Extended and Vietnamese subsets are supplied. `fonts.css` contains the matching font faces and Unicode ranges. Both families use the SIL Open Font License; original licenses are included.
